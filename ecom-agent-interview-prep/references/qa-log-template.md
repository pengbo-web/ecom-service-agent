# 电商客服 Agent 面试 · 问答复习集（错题本）

> 陪练过程中**问过的每一道题 + 标准答案**都沉淀在这，按模块归档，方便刷题复习。
> 每次会话新问的题，Claude 追加到对应模块小节下。
>
> **每条格式**：
> ```
> - **Q（YYYY-MM-DD ｜ 表现🟢/🟡/🔴）**：<问题>
>   **A**：<标准答案，含"为什么"，不只是结论>
>   **考点**：<一句话点出踩分点>　　**我的问题**：<答错/遗漏了什么，🟢可省>
> ```
> **表现**：🟢答得好 / 🟡有遗漏待巩固 / 🔴没答上（重点复习）。
> 复习时优先刷 🔴🟡；答顺了升级颜色。同题再问答得更好就**更新原条目**，不新增。
